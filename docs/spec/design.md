# Design

indexed has no graphical interface: its surface is a CLI, an MCP server and an LSP server. There is no visual design system, so design here means the interaction principles, output shapes and terminal UI patterns below.

- [UX principles](concepts/ux-principles.md): privacy first, fast and minimal, developer experience, composability.
- [Output formats](concepts/output-formats.md): what commands and tools print.
- [Rich UI patterns](tech/app/app-rich-ui-patterns.md): theme, markup safety, narrow terminals.
- [Search result contract](tech/app/app-search-result-contract.md): the machine-readable shape agents receive.
- [Logging strategy](tech/app/app-logging-strategy.md): what reaches stdout and stderr.
- [First-time setup](flows/first-time-setup.md): the first-run journey.
