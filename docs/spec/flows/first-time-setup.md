# First-Time Setup

1. Install: `uv tool install indexed-sh`
2. Verify: `indexed --version`
3. Prepare the default model: `indexed init`
4. Create first collection: `indexed index create files --collection docs --path ./docs`
5. Search: `indexed index search "query"`

**Critical:** This must work in <5 minutes.
