# Output Formats

| Format | Use Case | Example |
|--------|----------|---------|
| **Card** | Rich terminal display | Default for `search` |
| **Table** | Structured comparison | `inspect` collections |
| **Compact** | Quick scanning | Titles only |
| **JSON** | Scripting/piping | `--json` flag |
